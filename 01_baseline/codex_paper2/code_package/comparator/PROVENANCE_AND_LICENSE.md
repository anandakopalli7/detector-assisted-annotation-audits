# Provenance and release rights

The eight files under `paper2_compare/vendor` are exact copies of this user's existing Programme B research source, identified in `VENDOR_PROVENANCE.json`. New adapters, CLI, record format, verifier and fixtures are in `paper2_compare/` outside that directory. Vendored filenames and comments preserve their original historical development context; imports do not run their guarded standalone main functions.

Scientific method attribution and original-paper assumptions are documented in the existing D-P2-11 source register, assumption matrix and minimal protocol under `20_DESIGN/D_P2_11_v01` in the research root. This implementation does not copy original PPI/PPAT repositories or claim their native algorithms were reproduced. The portable code has no detector/image dependency and redistributes no dataset assets or third-party installed package binaries.

NumPy and SciPy remain installed dependencies with their own upstream license terms. Their versions and content hashes are recorded for qualification. This internal review release assigns no new public code license. Any future public code-license selection and publication remain the author's decision; D-P2-12 does not authorize either.
